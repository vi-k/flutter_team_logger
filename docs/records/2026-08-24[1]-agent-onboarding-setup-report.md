> **Состояние на 2026-08-24:** Сделано и смержено в main (этим коммитом).
> **Что это:** отчёт о первичной настройке проекта на автоматическое
> восстановление контекста AI-агентом (Claude, Codex) после обрыва сессии.
> **Связанные записи:** [2026-07-28[1]-team-logger-0.4.1-upgrade-plan.md](2026-07-28[1]-team-logger-0.4.1-upgrade-plan.md).

## Задача

Настроить проект так, чтобы любая AI-сессия (Claude Code или Codex), начатая
с нуля после непредвиденного обрыва предыдущей, могла восстановить полный
контекст без участия владельца.

## Сделано

- `AGENTS.md` — единая точка входа для обоих агентов: порядок чтения при
  старте сессии, карта `docs/`, правила git (мерж прямо в `main`, не
  смешивать чужие правки со своими), конвенция именования и структуры
  `docs/records/` (включая шаблон шапки и правило про вердикты в ревью),
  языковое правило, полный текст ceremony-правила публикации на pub.dev.
- `CLAUDE.md` — одна строка, `@AGENTS.md` (по образцу глобального
  `~/.claude/CLAUDE.md` → `@RTK.md`).
- `docs/handoff.md` — текущий срез состояния (версия, статус ветки,
  активная работа, статус проверки).
- `docs/backlog.md` — пожелания владельца. Создан переносом `TODO.md`
  (`git mv`, содержимое не менялось, только переименован заголовок
  «TODO» → «Бэклог»); `TODO.md` в корне удалён, дублирующего файла не
  осталось.
- `docs/architecture.md` — устройство пакета: публичный API (`Logs`,
  `LogItem`), механика `LogsState` (пауза/возобновление, режим "новые логи
  отдельно"), алгебра `Filter`/`FilterExp`/`FilterValue`, два сосуществующих
  механизма нотификации (`StreamNotifier` vs `ChangeNotifier`-based
  `Notifier`), мост `ansi_utils.dart`, внешние зависимости, назначение
  `example/`.
- `docs/conventions.md` — версионирование (minor пакета = minor
  `team_logger`), верификация через `dart analyze` (тестов нет), состав
  `analysis_options.yaml`, конвенция lock-файлов, языковое правило со
  ссылкой на `AGENTS.md` и оговоркой про уже существующие
  русскоязычные dartdoc-комментарии в `lib/`, стиль коммитов.
- `docs/records/` создан; существовавший
  `docs/superpowers/plans/2026-07-28-team-logger-0.4.1.md` перенесён туда как
  `2026-07-28[1]-team-logger-0.4.1-upgrade-plan.md` с добавленной шапкой
  состояния (тело плана не менялось); пустая директория
  `docs/superpowers/` удалена.
- `.pubignore` — помимо `docs/` теперь исключает `AGENTS.md` и `CLAUDE.md`
  из архива `pub.dev` (та же причина: внутренняя кухня).

## Решения, принятые по ходу

- `TODO.md` признан тем же самым бэклогом, который просил завести владелец,
  и перенесён, а не продублирован — два конкурирующих списка пожеланий были
  бы хуже одного.
- Существующий план-документ из `docs/superpowers/plans/` мигрирован в
  `docs/records/` по новой схеме вместо того, чтобы остаться единственным
  файлом старого формата в репозитории.
- Языковая конвенция не применена ретроактивно к уже существующим
  dartdoc-комментариям в `lib/` (часть написана по-русски) — это отдельная
  правка, не заказанная в этой сессии; оговорка зафиксирована в
  `docs/conventions.md`, чтобы не потерялась.

## Не сделано

- Локальный коммит создан, но не запушен в `origin` — пуш придержан до
  подтверждения владельца.
