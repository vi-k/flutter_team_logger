   в предыдущих коммитах этой же сессии; см. связанные отчёты).
2. Тег `v0.7.0` (lightweight, по образцу всех предыдущих тегов в репозитории)
   на коммит `Release 0.7.0`.
3. `git push origin main` и `git push origin v0.7.0`.
4. `dart pub publish --force` — успех: flutter_team_logger 0.7.0 загружен
   на pub.dev.

## Примечание

`dart pub publish` выдал ожидаемую подсказку про неинкрементальную версию
(0.5.0 → 0.7.0, а не 0.5.1/0.6.0) — это следствие принятой в проекте
конвенции версионирования (minor пакета = minor team_logger, промежуточные
версии team_logger пропускаются), а не ошибка.
