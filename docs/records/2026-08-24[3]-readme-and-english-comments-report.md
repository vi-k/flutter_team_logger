## Задача

Владелец попросил небольшой README (проект сырой, дорабатывать позже) и
сразу его русский перевод в `README.ru.md`, не публикуемый на pub.dev и
поддерживаемый в актуальном состоянии. Отдельно подтвердил: все комментарии
в коде, кроме самого перевода в `README.ru.md`, — по-английски.

## Сделано

- `README.md` — переписан: статус "ранняя стадия", что даёт пакет (`Logs`,
  `LogItem`), минимальный рабочий пример на основе `example/`, вместо
  шаблонных "Coming soon".
- `README.ru.md` — построчный перевод, добавлен в `.pubignore`.
- Правило синхронизации перевода и запрет на его публикацию — записаны в
  `AGENTS.md` (раздел «Язык») и `docs/conventions.md` (новый раздел
  «README.ru.md»), чтобы будущая сессия не потеряла контекст.
- `lib/src/logs.dart` и `lib/src/filter/filter.dart` — единственные два
  файла в `lib/` с русскоязычными doc-комментариями (проверено по всему
  диапазону символов кириллицы) — переведены на английский. По ходу
  исправлены две мелкие неточности в переводимом тексте: ссылка на
  несуществующий пакет `team_builder` (в двух местах — очевидно
  подразумевался `team_logger`) и задвоенная точка в конце одного
  предложения.
- Оговорка про недомигрированные русские комментарии в
  `docs/conventions.md` — снята: комментарии английские теперь.

## Не тронуто

`example/lib/data.dart` содержит кириллицу — это не комментарии, а тестовые
данные (казахстанские адреса/названия для демонстрации форматирования
логов), под правило не подпадают.

- `dart analyze` (корень и `example/`) — чисто.
- `dart pub publish --dry-run` — `README.ru.md` в архив не попадает,
