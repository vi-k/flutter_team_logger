# Конвенции

## Версионирование

Minor-версия `flutter_team_logger` следует за minor-версией `team_logger`
(прецеденты: team_logger 0.2.1 → пакет 0.2.0; 0.4.1 → 0.4.0; 0.5.1 → 0.5.0).

## Проверка изменений

Тестов в репозитории нет. Единственная линия защиты — `dart analyze` (в
корне и в `example/`) с результатом `No issues found!`. Это обязательное
условие перед коммитом, а не пожелание.

`analysis_options.yaml` включает `strict-casts`/`strict-inference`/
`strict-raw-types` и большой набор кастомных lint-правил поверх
`flutter_lints`. Не отключать точечно без причины, отражённой в комментарии
рядом с правилом (в файле уже есть примеры такого стиля — закомментированные
правила с пояснением, почему они выключены).

## Файлы окружения

- Корневой `pubspec.lock` не коммитится (конвенция для библиотек, см.
  `.gitignore`).
- `example/pubspec.lock` коммитится — `example/` это приложение, а не
  библиотека.
- `.pubignore` исключает `docs/` и файлы `AGENTS.md`/`CLAUDE.md` из архива
  `pub.dev` — это внутренняя кухня, не для потребителей пакета.

## Язык

Полное правило — в `AGENTS.md` (раздел «Язык»). Коротко: внутренние
документы и общение с владельцем — по-русски, публичные артефакты
(`README.md`, `CHANGELOG.md`, dartdoc, сообщения коммитов, тексты ошибок) —
по-английски.

Оговорка: часть существующих dartdoc-комментариев в `lib/` написана по-русски
— это осталось до принятия этой конвенции и не мигрировано ретроактивно.
Новые и правящиеся комментарии — по-английски; массовый перевод старых без
отдельного запроса владельца не делать.

## Коммиты

Сообщения коммитов — по-английски. Для рутинных правок (версии, зависимости,
конфигурация) сложился стиль `chore: ...` (см. историю). Мержить прямо в
`main`, без PR (см. `AGENTS.md`).
