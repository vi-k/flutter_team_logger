# Конвенции

## Версионирование

Minor-версия `flutter_team_logger` следует за minor-версией `team_logger`
(прецеденты: team_logger 0.2.1 → пакет 0.2.0; 0.4.1 → 0.4.0; 0.5.1 → 0.5.0;
0.7.0 → 0.7.0 — промежуточные team_logger 0.5.2/0.6.0 пропущены, отдельного
релиза пакета под них не было).

## Проверка изменений

`dart analyze` (в корне и в `example/`) с результатом `No issues found!` —
обязательное условие перед коммитом, а не пожелание.

Тесты: `flutter test`.

- `test/log_node_test.dart` — модель дерева данных лога, чистая логика без
  Flutter. Появляется такая логика — покрывать её тестами.
- `test/log_details_test.dart` — smoke-тест экрана деталей: рисуется ли,
  переключаются ли режимы, раскрывается ли узел по тапу, открывается ли лог
  без данных. Не попиксельная проверка, а проверка того, что экран собран и
  реагирует, — именно она поймала лишний раскрытый уровень.

Сплошного покрытия виджетов нет и не планируется: на ранней стадии его
сопровождение дороже пользы. Один smoke-тест на экран — разумный минимум.

`analysis_options.yaml` включает `strict-casts`/`strict-inference`/
`strict-raw-types` и большой набор кастомных lint-правил поверх
`flutter_lints`. Не отключать точечно без причины, отражённой в комментарии
рядом с правилом (в файле уже есть примеры такого стиля — закомментированные
правила с пояснением, почему они выключены).

## Файлы окружения

- Корневой `pubspec.lock` не коммитится (конвенция для библиотек, см.
  `.gitignore`).
- `example/pubspec.lock` коммитится — `example/` это приложение, а не
  библиотека.
- `.pubignore` исключает `docs/`, `AGENTS.md`, `CLAUDE.md` и `README.ru.md`
  из архива `pub.dev` — это внутренняя кухня, не для потребителей пакета.

## Язык

Полное правило — в `AGENTS.md` (раздел «Язык»). Коротко: внутренние
документы и общение с владельцем — по-русски, весь код и комментарии в
`lib/`/`example/` (включая dartdoc), `README.md`, `CHANGELOG.md`, сообщения
коммитов и тексты ошибок — по-английски. Единственное исключение —
`README.ru.md` (см. ниже).

## README.ru.md

Русский перевод `README.md`, не публикуется на pub.dev. Правишь
`README.md` — в том же заходе обновляешь `README.ru.md`: перевод не должен
отставать.

## Коммиты

Сообщения коммитов — по-английски. Для рутинных правок (версии, зависимости,
конфигурация) сложился стиль `chore: ...` (см. историю). Мержить прямо в
`main`, без PR (см. `AGENTS.md`).
